# Frontend Cards

Тренажёр вопросов для фронтенд-собеседований: 273 карточки, интервальные повторения, работает офлайн и ставится на iPhone как приложение (PWA).

## Как устроено

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка и PWA-мета для iOS |
| `styles.css` | Стили (тёмная/светлая тема) |
| `app.js` | Вся логика: интервальные повторения, рендер markdown, IndexedDB |
| `data/questions.json` | Вопросы: `id`, `cat`, `q` (вопрос), `s` (short answer), `d` (подробно), `x` (Senior+) |
| `data/experience.md` | Истории «From my experience» к вопросам — правь как обычный текст |
| `data/questions.ru.md` | Русский перевод вопросов (кнопка EN/RU в шапке). Формат: `## id`, заголовок, `--- short`, `--- details` |
| `data/experience.ru.md` | Русские версии историй, тот же формат, что у `experience.md` |
| `sw.js` | Service worker: офлайн-кэш, стратегия network first |
| `manifest.webmanifest` | Имя, иконки, standalone-режим |

Прогресс хранится в IndexedDB (база `fe-cards`):
- `cards` — уровень каждой карточки (коробка 0–5, когда повторять, сколько раз знал/не знал);
- `kv` — избранное, активность по дням, настройки;
- `reviews` — журнал каждого ответа (`id`, оценка, коробка, время).

Бэкап: Настройки → «Сохранить файлом» или «Показать код».

## Истории из опыта

`data/experience.md`, формат:

```md
## js-closure
Текст истории в markdown.
```

`id` вопроса видно в адресе карточки в каталоге (`#/q/js-closure`). Комментарии `<!-- -->` в приложении не показываются.

Если меняешь историю, поправь и русскую версию в `data/experience.ru.md`. Если её там нет, при выбранном RU покажется английская.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000. Через `file://` не заработает: вопросы грузятся через `fetch`.

## Деплой на GitHub Pages

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту сайт будет на `https://<username>.github.io/<repo>/`.

После правок просто пушь: service worker берёт файлы из сети в первую очередь, так что обновление приезжает при следующем открытии приложения (если сети нет — работает из кэша).

## Установка на iPhone

Открыть ссылку в Safari → «Поделиться» → «На экран „Домой“». Важно: у установленного приложения своё хранилище, отдельное от Safari, поэтому прогресс из вкладки браузера туда не переедет (перенеси через бэкап).
